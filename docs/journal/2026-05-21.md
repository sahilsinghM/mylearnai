### Architecture decisions
- **SSE format**: raw text chunks (not JSON-wrapped). Error sentinel is JSON `{"error":true}` to avoid collision with real Claude text.
- **Page structure**: server wrapper (`tutor/page.tsx`) + client child (`TutorChat.tsx`) — matches existing dashboard/plan pattern. Supabase auth and week context resolved server-side.
- **`cleanHistory` ref**: tracks only fully-completed turns for API calls. Display state (`messages`) stays separate. Prevents partial turns from being sent to the API on retry or end-session.
- **Bootstrap**: empty `useEffect` fires on mount → calls `streamAssistant([])` → API injects `"Begin the session."` → Claude opens with first question.

### Bugs fixed during review
1. **SSE newline escaping** — Claude text chunks can contain `\n`. Raw `data: ${text}\n\n` breaks SSE framing. Fixed: escape `\n` → `\\n` on emit, unescape on client.
2. **`endSession` concurrent race** — `endSession` didn't guard on `isSending`. If a stream was in-flight, close-session would call with an incomplete `cleanHistory`. Fixed: added `isSending` check.
